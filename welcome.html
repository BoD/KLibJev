KLibJev

     

A Jev API client library for Kotlin.

KLibJev is a Kotlin Multiplatform client for accessing the Jev API. It handles authentication and supports evaluating text or structured data with yes/no (Noul), multiple-choice (Choice), and scoring (Score) questions, and receive typed answers with probabilities.

Since v1.1.0, images and Box questions are also supported.

Usage

Add the library to your Kotlin project:

dependencies { implementation("org.jraf.klibjev:klibjev:$latest_version") }

Create a client with your Jev API key and call evaluate:

JevClient(JevClient.Configuration("YOUR_API_KEY")).use { client -> val state = State("Bonjour !") val question = Noul("Is this a greeting?") val answer = client.evaluate(state, question).getOrThrow().answers[question] println(answer) }

evaluate returns a Kotlin Result.

See the JVM sample for a more comprehensive example.
